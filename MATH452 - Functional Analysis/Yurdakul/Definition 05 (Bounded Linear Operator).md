
> [!def] [Definition 05 (Bounded Linear Operator)](Definition%2005%20%28Bounded%20Linear%20Operator%29.md) — Let $(E,\|\cdot\|_{E})$ and $(F,\|\cdot\|_{F})$ be normed linear spaces. A linear map $T\colon E\to F$ is a **bounded linear operator** if there exists $M>0$ such that $\|T(x)\|_{F}\leq M\|x\|_{E}$ for every $x\in E$.

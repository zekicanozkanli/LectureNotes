
> [!def] [[Definition 13 (Monotone Set Sequences)]]: A sequence $(A_n)$ of subsets of a set is **increasing** if $A_1\subseteq A_2\subseteq\cdots\subseteq A_n\subseteq A_{n+1}\subseteq\cdots$, and **decreasing** if $A_1\supseteq A_2\supseteq\cdots\supseteq A_n\supseteq A_{n+1}\supseteq\cdots$.

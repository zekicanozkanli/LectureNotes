
> [!def] [[Definition 34 (Measurable Map between Measurable Spaces)]]: For sets $X,Y$ with $\sigma$-algebras $\mathcal A_X,\mathcal A_Y$, a function $f:X\to Y$ is **$\mathcal A_X,\mathcal A_Y$-measurable** if $f^{-1}(C)\in\mathcal A_X$ for every $C\in\mathcal A_Y$.

> [!rem] The initial real-valued measurability definition is equivalently $\mathcal A,\mathcal B(\mathbb R)$-measurability.

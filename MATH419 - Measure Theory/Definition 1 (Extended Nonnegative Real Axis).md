> [!def] [[Definition 1 (Extended Nonnegative Real Axis)]]: The extended non-negative real axis is $[0,\infty]=[0,\infty)\cup\{\infty\}$, in which the algebraic operations and order relations of $[0,\infty)$ are extended as follows:
> i. For any $x\in[0,\infty]$, $x+\infty=\infty+x=\infty$.
> ii. For any $x\in(0,\infty]$, $x\cdot\infty=\infty\cdot x=\infty$.
> iii. $0\cdot\infty=\infty\cdot0=0$.
> iv. For any $x\in[0,\infty)$, $x<\infty$.

###### Motivation.

Some subsets have infinite measure; the real line has infinite length.

###### Remarks.

If $a_n=\infty$ for all $n\ge k$, set $\lim a_n=\infty$. A nonnegative series has value $\infty$ if one term is $\infty$; otherwise it converges to a finite real number or to $\infty$. Thus all series in $[0,\infty]$ converge in this extended sense.
$$\sum_{n=1}^\infty a_n=\lim_{N\to\infty}\sum_{n=1}^N a_n=\sup_{\substack{F\subseteq\mathbb N^+\\F\text{ finite}}}\sum_{n\in F}a_n.$$
For an arbitrary family $\{a_i:i\in I\}\subseteq[0,\infty]$,
$$\sum_{i\in I}a_i=\sup_{\substack{F\subseteq I\\F\text{ finite}}}\sum_{n\in F}a_n.$$
The final summand index follows the source.

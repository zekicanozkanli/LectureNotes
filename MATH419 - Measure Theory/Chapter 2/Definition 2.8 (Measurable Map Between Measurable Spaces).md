
> [!def] [[Definition 2.8 (Measurable Map Between Measurable Spaces)]]: In some work, however, one wishes to define measurability for a function $f$ from one **measurable** space $(X,\mathcal X)$ into another measurable space $(Y,\mathcal Y)$. In this case one says that $f$ is measurable in case the set
> 
> $$
> f^{-1}(E)=\{x\in X:f(x)\in E\}
> $$
> 
> belongs to $\mathcal X$ for every set $E$ belonging to $\mathcal Y$.

> [!rem] When $Y=\mathbb R$ and $\mathcal Y=\mathcal B$, this definition is equivalent to [[Definition 2.3 (Measurable Function)]]. It also displays the analogy with continuity: continuous functions pull open sets back to open sets, while measurable functions pull measurable sets back to measurable sets.
> 
> The initial real-valued definition is equivalent to measurability from $(X,\mathcal A)$ to $(\mathbb R,\mathcal B(\mathbb R))$.

# Exercise 11 (Measure Restricted To A Measurable Set)

^nt-461c5565ea25fa68

###### Statement.

Let $(X,\mathcal A,\mu)$ be a measure space. Fix $E\in\mathcal A$ and define $\mu_E(A)=\mu(E\cap A)$ for $A\in\mathcal A$. Show that $\mu_E$ is a measure on $\mathcal A$. Use [[Definition 10 (Measure)]] and [[Definition 7 (Sigma-Algebra)]].

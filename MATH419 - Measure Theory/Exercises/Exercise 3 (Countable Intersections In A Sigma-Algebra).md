# Exercise 3 (Countable Intersections In A Sigma-Algebra)

###### Statement.

If $(A_n)$ is a sequence in a $\sigma$-algebra $\mathcal A$, show that $\bigcap_{n=1}^\infty A_n\in\mathcal A$. Use [[Definition 7 (Sigma-Algebra)]].


> [!thm] [[Theorem 7 (Reciprocal Limit Criteria)]]: For finite $w_0$, $\lim_{z\to\infty}f(z)=w_0$ if and only if $\lim_{z\to0}f(1/z)=w_0$. Also $\lim_{z\to z_0}f(z)=\infty$ if and only if $\lim_{z\to z_0}1/f(z)=0$, and $\lim_{z\to\infty}f(z)=\infty$ if and only if $\lim_{z\to0}1/f(1/z)=0$.

###### Examples.
> [!eg] Ex. 1: $\lim_{z\to\infty}(2z+3)/(z+i)=2$ (see [[Exercise 5 (Rational Limit at Infinity)]]).

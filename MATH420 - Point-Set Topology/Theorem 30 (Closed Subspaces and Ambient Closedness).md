
> [!thm] [Theorem 30 (Closed Subspaces and Ambient Closedness)](Theorem%2030%20%28Closed%20Subspaces%20and%20Ambient%20Closedness%29.md): For a subspace $Y$ of $(X,\mathcal{T})$, $(\mathcal{T}_Y)_K\subseteq\mathcal{T}_K$ if and only if $Y\in\mathcal{T}_K$.

###### Proof.
> [!pf] *Proof.* ($\Rightarrow$) The set $Y$ is closed in itself, so the inclusion implies that $Y$ is closed in $X$. ($\Leftarrow$) If $Y$ is closed in $X$, then $F\cap Y$ is closed in $X$ for every ambient closed set $F$. The characterization [Proposition 09 (Closed Sets in Subspaces)](Proposition%2009%20%28Closed%20Sets%20in%20Subspaces%29.md) therefore gives $(\mathcal{T}_Y)_K\subseteq\mathcal{T}_K$.$\blacksquare$


> [!thm] [Theorem 39 (Equivalence Relations and Partitions)](Theorem%2039%20%28Equivalence%20Relations%20and%20Partitions%29.md): Every equivalence relation on $X$ determines a partition into its distinct equivalence classes:  
> i. For $x,y\in X$, either $[x]=[y]$ or $[x]\cap[y]=\emptyset$.  
> ii. $\bigcup_{x\in X}[x]=X$.  
> Conversely, a partition $\mathcal{P}$ determines an equivalence relation by $x\sim y$ if and only if $x$ and $y$ belong to the same member of $\mathcal{P}$. The set of equivalence classes is denoted $X/{\sim}$.

> [!rem] No proof is supplied in the attached lecture.

###### Examples.
> [!eg] Ex. 1: The rectangle partition with reversed heights has two-point boundary classes $\{(0,y),(3,1-y)\}$ and singleton classes elsewhere (see [Exercise 94 (Rectangle Partition with Reversed Heights)](Exercises/Exercise%2094%20%28Rectangle%20Partition%20with%20Reversed%20Heights%29.md)).

> [!eg] Ex. 2: The equal-height version has boundary classes $\{(0,y),(3,y)\}$ and singleton classes elsewhere (see [Exercise 95 (Rectangle Partition with Equal Heights)](Exercises/Exercise%2095%20%28Rectangle%20Partition%20with%20Equal%20Heights%29.md)).

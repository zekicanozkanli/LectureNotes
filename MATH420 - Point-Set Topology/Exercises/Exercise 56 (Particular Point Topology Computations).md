(a) Show that $\mathcal T$ is a topology, called the particular point topology. (b) Find all $\mathcal T$-closed subsets. (c) If a sequence $(x_n)$ converges to $x_0$, what can be said about $(x_n)$? (d) In the particular point topology on $\mathbb R$ with $x_0=5$, let $A=\{3,6\}$. Find its interior, exterior, boundary, closure, isolated-point set $I(A)$, and derived set $\widetilde A$.

> [!rem] The isolated-point set $I(A)$ and derived set $\widetilde{A}$ are defined in [Definition 21 (Accumulation and Isolated Points)](../Definition%2021%20%28Accumulation%20and%20Isolated%20Points%29.md).

# Exercise 16 (The Singleton Basis For A Discrete Topology)

Let $(X,\mathcal D)$ be the discrete space. Show that the class $\mathcal B=\{\{x\}\mid x\in X\}$ is a base for $\mathcal D$.

###### Proof.

> [!proof]
> i. Every singleton is $\mathcal D$-open, hence $\mathcal B$ is a sub-collection of $\mathcal D$-open subsets of $X$.
> ii. For any $U \in \mathcal D$, we can write $U = \bigcup_{u \in U}\{u\}$ by the definition of union.

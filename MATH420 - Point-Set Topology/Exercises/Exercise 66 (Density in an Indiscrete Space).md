
> [!ex] [[Exercise 66 (Density in an Indiscrete Space)]]: Let $(X,\mathcal T)$ be an indiscrete topological space. Determine all its dense subsets.

###### Solution.
> [!sol] *Solution.* The only nonempty open set is $X$. For any nonempty $A\subseteq X$, $A\cap X=A\ne\emptyset$, so [[Proposition 8 (Density via a Basis)]] gives $\overline A=X$. Thus every nonempty subset of $X$ is dense.$\blacksquare$

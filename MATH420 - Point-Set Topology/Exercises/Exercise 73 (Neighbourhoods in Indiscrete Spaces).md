
> [!ex] [Exercise 73 (Neighbourhoods in Indiscrete Spaces)](Exercise%2073%20%28Neighbourhoods%20in%20Indiscrete%20Spaces%29.md): Let $(X,\mathcal{T})$ be indiscrete and $x\in X$. Determine $\eta(x)$.

###### Solution.
> [!sol] *Solution.* By definition, $\eta(x)=\{N\subseteq X\mid x\in U\subseteq N\text{ for some }U\in\mathcal{T}\}$. Since $\mathcal{T}=\{\emptyset,X\}$, the only possible open set containing $x$ is $X$. Thus $x\in X\subseteq N\subseteq X$, so $\eta(x)=\{X\}$.$\blacksquare$


> [!ex] [[Exercise 31 (Convergence in a Four-Point Space)]]: Let $X=\{a,b,c,d\}$ and $\mathcal T$ be the topology generated by $\mathcal S=\{\{a,b, c\},\{a,c\},\{d\}\}$. Consider the sequences $(x_n)=(c,c,c,\ldots)$ and $(y_n)=(a,c,a,c,\ldots)$. Determine the convergence of $(x_n)$ and $(y_n)$.

###### Proof.
> [!pf] *Proof.* We use [[Theorem 8 (Convergence via a Subbase)]].
> Consdier $(x_n)=(c,c,c,\ldots)$.
> (Case I ($a$)) The subbasic sets containing $a$ are $\{a,b,c\}$ and $\{a,c\}$. Both contain $x_n=c$ for every $n\ge1$. Hence $x_n\to a$.
>
> (Case II ($b$)) The only subbasic set containing $b$ is $\{a,b,c\}$, which contains every term of the sequence. Therefore $x_n\to b$.
>
> (Case III ($c$)) The subbasic sets containing $c$ are $\{a,b,c\}$ and $\{a,c\}$. Both contain every term of the sequence, so $x_n\to c$.
>
> (Case IV ($d$)) The set $\{d\}$ is an open set containing $d$, but $x_n=c\notin\{d\}$ for every $n\ge1$. Thus $x_n\not\to d$.
>
> Consequently, the set of limits of $(x_n)$ is precisely $\{a,b,c\}$. 
> 
> Now consider $(y_n)=(a,c,a,c,\ldots)$.
>
> (Case I ($a$)) The subbasic sets containing $a$ are $\{a,b,c\}$ and $\{a,c\}$. Since $y_n\in\{a,c\}\subseteq\{a,b,c\}$ for every $n\ge1$, each contains all terms of the sequence. Hence $y_n\to a$.
>
> (Case II ($b$)) The only subbasic set containing $b$ is $\{a,b,c\}$. Since $y_n\in\{a,b,c\}$ for every $n\ge1$, it follows that $y_n\to b$.
>
> (Case III ($c$)) The subbasic sets containing $c$ are $\{a,b,c\}$ and $\{a,c\}$. Both contain $y_n$ for every $n\ge1$. Therefore $y_n\to c$.
>
> (Case IV ($d$)) The set $\{d\}$ is an open set containing $d$, but $y_n\notin\{d\}$ for every $n\ge1$. Thus no positive integer $n_0$ satisfies $y_n\in\{d\}$ for all $n\ge n_0$, so $y_n\not\to d$.
>
> Consequently, the set of limits of $(y_n)$ is precisely $\{a,b,c\}$. $\blacksquare$

> [!pf] *Proof.* $\blacksquare$


> [!ex] [Exercise 100 (Separation in Three-Point Spaces)](Exercise%20100%20%28Separation%20in%20Three-Point%20Spaces%29.md): Let $X=\{a,b,c\}$, $\mathcal{T}=\{\emptyset,\{a\},\{b,c\},X\}$, and $\mathcal{V}=\{\emptyset,\{a\},\{a,b\},X\}$. Determine whether the two spaces are $T_0$. Determine also whether $(X,\mathcal{V})$ is $T_1$.

###### Solution.
> [!sol] *Solution.* For $(X,\mathcal{T})$, every open set containing $b$ contains $c$, and conversely, so the space is not $T_0$. For $(X,\mathcal{V})$, the set $\{a\}$ contains $a$ and excludes $b$, and also contains $a$ and excludes $c$. For the pair $b,c$, the open set $\{a,b\}$ contains $b$ and excludes $c$. Hence $(X,\mathcal{V})$ is $T_0$. It is not $T_1$: although $a\in\{a\}$ and $b\notin\{a\}$, every $\mathcal{V}$-open set containing $b$ also contains $a$. Thus there is no open $V$ with $b\in V$ and $a\notin V$.$\blacksquare$

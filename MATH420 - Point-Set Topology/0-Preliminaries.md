
###### Functions.
Let $A, B \subseteq X$ and $C, D \subseteq Y$ be any sets and $f:X\to Y$ be any function. We have the following properties:

i. $A\subseteq f^{-1}(f(A))$.
ii. $A=f^{-1}(f(A))$ if $f$ is one-to-one.

iii. $f(f^{-1}(C))\subseteq C$.
iv. $C=f(f^{-1}(C))$ if $f$ is onto.

v. $A\subseteq B$ implies $f(A)\subseteq f(B)$.
vi. $C\subseteq D$ implies $f^{-1}(C)\subseteq f^{-1}(D)$.

vii. $f(A\cup B)=f(A)\cup f(B)$.
viii. $f^{-1}(C\cup D)=f^{-1}(C)\cup f^{-1}(D)$.

ix. $f(A\cap B)\subseteq f(A)\cap f(B)$.
x. $f(A\cap B)=f(A)\cap f(B)$ if and only if $f$ is one-to-one.
xi. $f^{-1}(C\cap D)=f^{-1}(C)\cap f^{-1}(D)$.

xii. $f(A)\setminus f(B)\subseteq f(A\setminus B)$.
xiii. $f(A)\setminus f(B)=f(A\setminus B)$ if and only if $f$ is one-to-one.
xiv. $f^{-1}(Y\setminus C)=f^{-1}(Y)\setminus f^{-1}(C)$.

xv. $Y\setminus f(A)\subseteq f(X\setminus A)$ if and only if $f$ is onto.
xvi. $Y\setminus f(A)=f(X\setminus A)$ if and only if $f$ is a bijection.

xvii. $f(A)=f(B)$ implies $A=B$, if $f$ is one-to-one.
xviii. $f^{-1}(C)=f^{-1}(D)$ implies $C=D$, if $f$ is onto.

xix. If $\{A_i\}_{i\in I}$ is a collection of subsets of $X$, then
$$f^{-1}\left(\bigcup_{i\in I}A_i\right)=\bigcup_{i\in I}f^{-1}(A_i) \qquad \text{and} \qquad f^{-1}\left(\bigcap_{i\in I}A_i\right)=\bigcap_{i\in I}f^{-1}(A_i).$$

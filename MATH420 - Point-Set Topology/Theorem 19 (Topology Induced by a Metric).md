
> [!thm] [Theorem 19 (Topology Induced by a Metric)](Theorem%2019%20%28Topology%20Induced%20by%20a%20Metric%29.md): Let $(X,d)$ be a metric space. For each $x\in X$, set $\eta_d(x)=\{N\subseteq X\mid S_d(x,\varepsilon)\subseteq N\text{ for some }\varepsilon>0\}$. These classes satisfy the neighbourhood properties and determine a unique topology $\mathcal{T}_d$ on $X$. It is called the **metric topology**, the **topology induced by $d$**, or the **topology generated by $d$**.

###### Proof.
> [!pf] *Proof.* For property (i), if $S_d(x,\varepsilon)\subseteq N$, then $x\in S_d(x,\varepsilon)\subseteq N$. For (ii), if $S_d(x,\varepsilon_i)\subseteq N_i$ for $i=1,2$, let $\varepsilon=\min\{\varepsilon_1,\varepsilon_2\}>0$. Then $S_d(x,\varepsilon)\subseteq S_d(x,\varepsilon_1)\cap S_d(x,\varepsilon_2)\subseteq N_1\cap N_2$, so $N_1\cap N_2\in\eta_d(x)$. For (iii), if $N\in\eta_d(x)$ and $N\subseteq N'\subseteq X$, choose $\varepsilon>0$ with $S_d(x,\varepsilon)\subseteq N$. Then $S_d(x,\varepsilon)\subseteq N'$, so $N'\in\eta_d(x)$. For (iv), choose $S_d(x,\varepsilon)\subseteq N$ and set $M=S_d(x,\varepsilon/2)$. For $y\in M$, let $\delta=\varepsilon/2$. If $z\in S_d(y,\delta)$, the triangle inequality gives $d(x,z)\leq d(x,y)+d(y,z)<\varepsilon/2+\varepsilon/2=\varepsilon$. Thus $S_d(y,\delta)\subseteq S_d(x,\varepsilon)\subseteq N$, so $N\in\eta_d(y)$. The result now follows from [Theorem 17 (Topology from Neighbourhood Systems)](Theorem%2017%20%28Topology%20from%20Neighbourhood%20Systems%29.md), whose construction is $\mathcal{T}_d=\{U\subseteq X\mid U\in\eta_d(x)\text{ for every }x\in U\}$.$\blacksquare$

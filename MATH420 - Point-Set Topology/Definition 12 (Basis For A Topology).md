> [!def] [[Definition 12 (Basis For A Topology)]]: Let $(X,\mathcal T)$ be a topological space. A class $\mathcal B$ of $\mathcal T$-open subsets of $X$, i.e. $\mathcal B\subseteq\mathcal T$, is a base or a basis for $\mathcal T$ if every open set $U\in\mathcal T$ is the union of members of $\mathcal B$.

###### Motivation.

Suppose we have an arbitrary class $\mathcal B$ of subsets of a nonempty set $X$. When will the class $\mathcal B$ be a base for some topology on $X$? Since $X$ is open in every topology on $X$, clearly $X=\bigcup\mathcal B=\bigcup\{B\mid B\in\mathcal B\}$. [[Theorem 4 (Conditions For A Class To Be A Basis)]] gives necessary and sufficient conditions for a class of subsets of $X$ to be a base for some topology on $X$.

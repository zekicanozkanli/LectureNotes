# Images And Inverse Images

Let $X$ and $Y$ be any sets and $f:X\to Y$ be a function.

i. $A\subseteq B$ implies $f(A)\subseteq f(B)$.

ii. $f(A\cup B)=f(A)\cup f(B)$.

iii. $f(A\cap B)\subseteq f(A)\cap f(B)$.

iv. $f$ is one-to-one iff $f(A\cap B)=f(A)\cap f(B)$.

v. $f$ is onto iff $Y\setminus f(A)\subseteq f(X\setminus A)$.

vi. $f$ is a bijection iff $f(X\setminus A)=Y\setminus f(A)$.

vii. $f(A)\setminus f(B)\subseteq f(A\setminus B)$.

viii. $f$ is one-to-one iff $f(A)\setminus f(B)=f(A\setminus B)$.

ix. $f^{-1}(C\cup D)=f^{-1}(C)\cup f^{-1}(D)$.

x. $f^{-1}(C\cap D)=f^{-1}(C)\cap f^{-1}(D)$.

xi. $f^{-1}(Y\setminus C)=f^{-1}(Y)\setminus f^{-1}(C)$.

xii. $A\subseteq f^{-1}(f(A))$.

xiii. $f(f^{-1}(C))\subseteq C$.

xiv. $C\subseteq D$ implies $f^{-1}(C)\subseteq f^{-1}(D)$.

xv. If $f$ is one-to-one, then $A=f^{-1}(f(A))$.

xvi. If $f$ is onto, then $C=f(f^{-1}(C))$.

xvii. If $f$ is one-to-one, then $f(A)=f(B)$ implies $A=B$.

xviii. If $f$ is onto, then $f^{-1}(C)=f^{-1}(D)$ implies $C=D$.

xix. The handout states: if $\{A_i\}_{i\in I}$ is a collection of subsets of $X$, then
$$f^{-1}\left(\bigcup_{i\in I}A_i\right)=\bigcup_{i\in I}f^{-1}(A_i)$$
and
$$f^{-1}\left(\bigcap_{i\in I}A_i\right)=\bigcap_{i\in I}f^{-1}(A_i).$$

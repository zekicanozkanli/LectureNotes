
> [!prop] [[Proposition 5 (Homeomorphism Is An Equivalence Relation)]]: Let $\mathscr{T}$ be any collection of topological spaces. Then $\cong$ is an equivalence relation on $\mathscr{T}$.

Hence, $\mathscr{T}$ can be partitioned into equivalence classes each of which contains mutually homeomorphic spaces.

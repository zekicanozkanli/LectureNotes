
> [!def] [[Definition 1 (Graph)]]: A graph $G$ is a mathematical object consisting of a finite nonempty set of objects called vertices $V(G)$ (the vertex set), and a set of edges $E(G)$ (the edge set). An edge is a two-element subset of the vertex set.

An edge $e=\{u,v\}$ is typically written $uv$ or $vu$.

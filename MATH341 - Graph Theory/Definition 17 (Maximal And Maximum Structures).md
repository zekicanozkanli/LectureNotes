
> [!def] [[Definition 17 (Maximal And Maximum Structures)]]: A graph, subgraph, or structure is maximal if no larger one contains it; it is maximum if it is as large as possible. Minimal and minimum are defined similarly.,

###### Examples.

i. The set $S_1=\{1, 4\}$ is a maximal clique, as no other vertex can be added in $S_1$ to maintain its clique structure. Similarly, $S_2 = \{1, 2, 3\}$ is a maximal clique, and also the maximum.
![[gemini-svg (8).svg|554]]
ii. The set $S_1 = \{1\}$ is a maximal independent set. Every other vertex is adjacent to $1$, so adding any vertex will not produce an independent set. $S_2 = \{2\}$ is *not* a maximal independent set as it can be enlarged while remaining independent, say $T=\{2, 3\}$. The set $U=\{2, 3, 4, 5\}$ is the maximum independent set.![[gemini-svg (9).svg|496]]

# Labeled And Unlabeled Graphs

A labeled graph has named vertices; an unlabeled graph has unnamed vertices and represents all labelings with the same structure. Unless otherwise specified, the source uses “graph” for an unlabeled graph.

Graphs are isomorphic when their vertices can be renamed so that the graphs are the same; different vertex positions do not change the graph. For isomorphic unlabeled graphs, the source writes $G=H$.

The standard labeled vertex set is $[n]=\{1,\ldots,n\}$.

> [!def] [[Definition 22 (Complement And Decomposition)]]: The complement $\overline G$ of a graph $G$ has the same vertex set and edge $uv \in V(\overline G)$  if and only if $uv\notin E(G)$. A decomposition of $G$ is a set of nonempty subgraphs whose edge sets partition $E(G)$. These subgraphs decompose $G$.

Note that an empty graph is the complement of a complete graph of the same order. A graph $G$ of order $n$ and its complement, decompose $K_n$.

###### Examples.

i. $\overline{C_4}=2K_2$, so $\{C_4,2K_2\}$ is a decomposition of $K_4$.

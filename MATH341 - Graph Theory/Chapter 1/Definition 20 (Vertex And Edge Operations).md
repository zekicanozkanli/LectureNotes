
> [!def] [[Definition 20 (Vertex And Edge Operations)]]: An edge deletion $G-X$ is a unary operation that deletes an edge set $X$ from $E$. A vertex deletion $G-S$ is a unary operation that deletes a vertex set $S$ from $V$ together with all incident edges. Addition is similarly defined.

Recall that an edge $e=\{u, v\}$ is an unordered pair of vertices $u, v$. Hence deletion is well-defined. For an unlabeled graph, an unspecified deletion or addition is defined only when every eligible choice gives the same graph.
###### Examples.

i. For every edge $e$ of $C_n$, $C_n-e=P_n$.

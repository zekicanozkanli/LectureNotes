# Polygonal Presentations Of Surfaces

We can construct compact surfaces by taking a polygon in the plane and identifying its edges in pairs. We represent this gluing using boundary words.

###### Examples.

i. Torus: $S^1\times S^1=T^2$.

![Torus polygon with equally directed opposite edges](_support/attachments/23eac36d-M14-028e608b7dae.svg)

After gluing, there is one vertex because all four corners coincide; there are two edges.

ii. Sphere: $S^2$.

![Sphere presentation using a two-edged polygon](_support/attachments/23eac36d-M15-836db7b9012a.svg)

iii. Klein bottle. -no boundary

![Klein bottle polygon with one reversed edge direction](_support/attachments/23eac36d-M16-99027ec8e650.svg)
